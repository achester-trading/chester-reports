## 1. The rhythm

Every day has three slots and the sessions never idle.

| Slot | Who | What |
|---|---|---|
| **Overnight (≈ 23:00 → 07:00)** | sessions A and B | Two queued pastes each (a second message sent while the first runs is picked up when it ends). Branch-only: push, CI, a notes file, a needs-you list. No merge, no deploy, no units, no box. |
| **Morning (≈ 07:00–09:00)** | the operator, with Claude | Read the overnight reports — Claude reads each branch's notes file from the remote, so a garbled terminal report costs nothing. Rulings on the needs-you lists in chat, one at a time. |
| **Evening window (17:20–23:30 ET weekdays; weekends open, clear of Sunday 05:00)** | the operator | Merges of green, confirmed branches in the stated order; box backfills and dry runs; the day's rulings; then the next night's two pastes per session, written by Claude during the day. |

Rules of the cadence:

- **A paste is complete.** Every overnight paste ends with: push the branch, report the CI run and result, write `docs/briefs/<id>-notes.md` with a "Needs you" section, do not merge. The second paste of the night begins "after the first is pushed and reported; if it is still in progress, finish and report it first".
- **The notes file is the report.** Terminal reports wrap and truncate; the notes file on the branch does not. Claude reads it with `git show origin/<branch>:docs/briefs/<id>-notes.md`.
- **Branches are cheap; merges are the decision.** Nothing merges before CI is green, the operator says so, and — for items the sitting places — the sitting has confirmed. Overnight work never pre-empts a ruling; it only means the ruling has something finished to place.
- **One task, one machine** still holds: a paste goes to one session; a session runs one paste at a time. A hot-fix may pre-empt a running task (commit WIP first, as T3.4a did).
- **Merge day** after each sitting: the confirmed branches in a stated order, CLAUDE.md's layout and gate count resolved once in the last merge, the box backfills run in the same order, one dry run at the end.
- **Needs-you lists ≤ 5 items**, each a yes/no or a one-word ruling; anything larger is a chat decision, taken one at a time.
- **The operator's reading is the scarce resource.** Claude pre-reads every notes file and every dry-run log and brings the rulings, not the reports.

## 5. Risks the cadence adds, and the rule for each

- **Merge conflicts between parallel branches.** The merge order is stated before merge day; CLAUDE.md's layout and gate count are edited once, in the last merge; a branch that must build on another builds on it (AQ-9a on `imf-ifs-gold` if the client is shared) and says so.
- **Volume outrunning review.** No branch merges unread: Claude reads every notes file and brings a one-paragraph verdict with the rulings; the operator's word is the merge. If reading falls behind, branches wait — they do not expire.
- **The laptop.** Two sessions, never three; a library task runs in session B on the library worktree rather than as a third session. The full local gate suite stays off; CI is the validate.
- **A failing overnight paste.** A session that hits a wall stops and writes the notes file with what it found; nothing is retried blindly. The morning slot decides.
- **The box.** Overnight work never touches it. Box commands are the operator's, in the evening window, from the notes files' exact lines.

## 6. Rules carried forward (from v5, unchanged)

Paper trading only; sessions never place orders. No Brookfield-complex trades (blocklist in Python and SQLite). One task, one machine; every paste names its session. Sessions may validate, deploy and use git; they print unit commands, never run them; `decide.py record`, narrative confirm/reject, `.env`, register writes and `systemctl --user enable` are the operator's. A push to main is a box write and happens only inside the windows. CI is the validate. No secrets and no real position figures in any chat, commit or file. Code gates never read the live store. Reports never fetch. A session's "Resume this session with…" line means it exited.
