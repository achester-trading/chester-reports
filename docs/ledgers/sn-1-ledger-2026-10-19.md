# SN-1 ledger -- The release-day first hour: continue or fade (secondary notes, 4.1)

**Edition:** 2026-10-19, laptop run, public sources. A re-run against the box's store supersedes it (a new dated file).

**The pass rule is pre-registered** (ruled 17 Oct 2026): the rule the order states; where it states none, the rule the first (laptop) edition wrote is the registration. A box re-run may not change it, only apply it.

## Caveats

- ^TNX: Yahoo's hourly bars for the yield index start at 08:20 ET and are aligned at twenty past the hour, so the registered 07:00-08:00 bar never exists and every ^TNX day is not scored in this sample. The registration is not changed; the open note's own 5-minute readings (calc.release_first_hour) are the sample that can score the 10-year.
- A release date is FRED's; the print is assumed at 08:30 ET, as the release calendar schedules it.
- Two samples are never pooled: this is the first edition's; the note's own readings accrue from the first live open note.

The episodes are in `sn-1-ledger-2026-10-19-episodes.csv`, beside this file.
