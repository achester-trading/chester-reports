## If the 16:45 close misbehaves after the push

The push changes nothing the object computes (see the top). A problem at the
close would therefore be in the new feature computation — a slow or failing
`market_features compute`, which the close logs as `WARN market_features exited
…` and continues past. To stop computing the new series, restore the one file
the box runs differently, then push:

```powershell
git checkout 4a22aa4 -- altdata/market_features.py
git commit -m "Hold back the rates attribution series"
git push
```

The wrappers pull at their next start. The rows already written stay in the
store, read by nothing.
